# Use the following format:
# TYPE:FILENAME:TOPLEVELDIR:MOVIE_ALIAS:GENRE:REDUNDANCY
#
# FILENAME (required): Name of the file or folder (no path and NO FILE EXTENSION)
#   This will be globbed with a '*' to pickup multiple files (such as .srt files)
# TOPLEVELDIR (optional): Top level path to the movies (which contains Action, Adventure, etc)
#   If this is left empty, it will default to /data/Videos
#   Use '/data/Videos/Other/TV Series' for TV Series
# MOVIE_ALIAS (optional): The name to be given to the movie's directory
# GENRE (required): The name of the directory containing the movie
#   Should be directly under TOPLEVELDIR. Use 'Other/TV_Series' for TV Series
# REDUNDANCY (optional): Redundancy percentage to use for par2

#TYPE:FILENAME:TOPLEVELDIR:MOVIE_ALIAS:GENRE:REDUNDANCY
