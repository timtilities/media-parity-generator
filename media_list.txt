# Use the following format:
# TYPE:FILENAME:TOPLEVELDIR:MOVIE_ALIAS:GENRE:REDUNDANCY
#
# TYPE: Type of media (movie or tv). This changes how the folder structure is handled
# FILENAME: Name of the filename (no path and NO FILE EXTENSION)
#   This will be globbed with a '*' to pickup multiple files (such as .srt files)
# TOPLEVELDIR: Top level path to the movies (which contains Action, Adventure, etc)
#   If this is left empty, it will default to /data/Videos
#   Use '/data/Videos/Other/TV Series' for TV Series
# MOVIE_ALIAS: The name to be given to the movie's directory and the basename for the par2 files
# GENRE: The name of the directory containing the movie
#   Should be directly under TOPLEVELDIR. Use 'Other/TV_Series' for TV Series
# REDUNDANCY: Redundancy percentage to use for par2

#FILENAME:TOPLEVELDIR:MOVIE_ALIAS:GENRE:REDUNDANCY

tv:Test.Series.1:/scratch/Par2_Files/TestVids/Other/TV Series:TestSeries1:Other/TV_Series:
tv:Test.Series.2:/scratch/Par2_Files/TestVids/Other/TV Series:TestSeries2:Other/TV_Series:

Test.Video.1:/data/Videos/Test:TestVideo1:Fantasy:
Test.Video.2::TestVideo2:Action:
Test.Video.3::TestVideo3:Comedy:
